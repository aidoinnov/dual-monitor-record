# 사용자 안내

## 녹화 시작과 중지

다음 방법은 모두 동일한 녹화 제어 계층을 호출합니다.

- 메인 창의 **녹화 시작/중지** 버튼
- 우측 상단 메뉴 막대 아이콘
- 전역 단축키 `Command + F2`
- CLI/API/MCP 자동화 인터페이스

기능 키가 화면 밝기 같은 시스템 기능으로 설정됐다면 `Command + fn + F2`를 눌러야 할 수 있습니다.

## 저장 위치

기본값은 위치를 묻지 않고 `~/Movies/DualMonitorRecorder`에 자동 저장하는 것입니다. 설정에서 기본 저장 폴더와 녹화할 때마다 위치를 물을지 변경할 수 있습니다. 녹화 완료 후 **영상 열기**와 **폴더 열기**를 사용할 수 있습니다.

## 모니터 선택과 배치

메인 창의 **설정** 또는 메뉴 막대의 **설정…**을 엽니다.

1. 녹화할 모니터의 체크박스를 켭니다.
2. 미리보기에서 모니터 박스를 원하는 위치로 드래그합니다.
3. 설정 창을 닫습니다. 선택과 좌표는 즉시 저장됩니다.
4. 녹화를 시작하면 선택된 모니터만 해당 배치로 합성됩니다.

**실제 배치 불러오기**는 현재 macOS 디스플레이 좌표를 다시 읽습니다. 모니터별 화면 비율은 유지되고 빈 영역은 검은색으로 기록됩니다.

메인 창 또는 메뉴 막대의 **녹화 모니터 표시**를 누르면 선택된 화면마다 큰 번호와 파란 테두리가 3초간 나타납니다. 이 표시는 녹화 시작 전에 자동으로 닫히며 녹화 중에는 사용할 수 없습니다.

## 영상 출력

- 컨테이너: QuickTime MOV
- 코덱: HEVC/H.265
- 목표 프레임률: 30fps
- 최대 전체 캔버스: 7680×4320
- 화면별 최대 가로 기준: 2560픽셀
- 마우스 포인터: 포함
- 시스템 오디오와 마이크: 현재 미지원

전체 배치가 제한 크기를 넘으면 화면과 좌표를 같은 비율로 축소합니다.

## 메뉴 막대

메인 창을 닫아도 앱은 종료되지 않습니다. 메뉴 막대에서 녹화 시작/중지, 마지막 영상 및 폴더 열기, 메인 창과 설정 열기, 앱 완전 종료를 할 수 있습니다.

## 화면 기록 권한

권한은 코드서명된 앱 번들에 부여됩니다. 권한을 켠 직후에는 앱을 완전히 종료하고 다시 실행해야 합니다. 정식 인증서로 재빌드하면 권한이 유지되지만 임시 서명은 빌드마다 권한이 무효화될 수 있습니다.
